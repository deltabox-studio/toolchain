# Overview

Feel free to contribute to the development or docs.

> PRs from strangers are disabled for safety and work-load reasons.
>
> Only maintainers are able to create PRs for now.
>
> I only add trusted people as maintainers.
> You can become a maintainer by forking the repo and for a while create your own worthy PRs with bug fixes/features in the forked repo. Only then, you will be eligible to get reviewed for a maintainer role.

## Guides

- [Development](/contribute/development) covers the fork/clone setup, the local
  commands and the linter/formatter bootstrap fix.
- [Documentation](/contribute/documentation) covers writing, previewing and
  building the docs.
