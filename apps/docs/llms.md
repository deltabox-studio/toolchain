# LLMs

This documentation is published in machine-readable forms so LLMs and coding
agents can read it efficiently, following the [llms.txt](https://llmstxt.org)
standard:

- [`/llms.txt`](/llms.txt) — a concise, link-first overview: a short description,
  how the toolchain works, and a table of contents linking to the Markdown
  version of every page. Small enough to fit in a context window.
- [`/llms-full.txt`](/llms-full.txt) — the **entire** documentation concatenated
  into a single Markdown file, for when an agent wants everything in one fetch.

Every page is also available as raw Markdown by appending `.md` to its URL (eg.
`/guide/tsconfig.md`).

## When the site is unavailable

If `https://toolchain.deltabox.studio` is down, the same documentation lives in
the repository at
[github.com/deltabox-studio/toolchain/tree/main/apps/docs](https://github.com/deltabox-studio/toolchain/tree/main/apps/docs).
