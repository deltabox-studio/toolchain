# @deltabox/toolchain-project

Project and workspace scaffolding generators: TypeScript roots, monorepos, catalogs, package.json, tsconfig and Vite/dbx config files.

Part of **deltabox toolchain** - a superset of [Vite+](https://viteplus.dev) with project synchronization, a config generator, tsconfig management, MCP server, CI/changelog automation, providers, catalogs and a VS Code extension. Use it as a Vite plugin or standalone.

## Install

```sh
yarn add -D @deltabox/toolchain-project
# or: npm install -D @deltabox/toolchain-project
```

## Public API

The package root exports its public API. Included modules cover: scaffolding generators for TypeScript projects, monorepo roots and workspaces, catalogs and project config generation.

It is also available through the umbrella subpath `@deltabox/toolchain/project`.
