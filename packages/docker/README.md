# `@deltabox/toolchain-docker`

Dockerfile, `.dockerignore` and compose generation for `@deltabox/toolchain`.

- `dockerFiles()` / `writeDockerFiles()` render the artifacts for a project
  (used by `dbx create --containerize`).
- `dockerSyncTask()` writes the managed artifacts from the `docker` config
  section.
- Vite+ projects build with `ghcr.io/voidzero-dev/vite-plus`; Bun projects use
  `oven/bun`, and other Node projects use `node:<version>`.
- Multi-stage builds, non-root runtime users, an HTTP `HEALTHCHECK` and an
  optional compose file are generated by default.

```ts
toolchain: {
    docker: {
        image: 'acme/api',
        port: 3000,
        compose: true,
    },
}
```
