# `@deltabox/toolchain-docker`

Dockerfile, `.dockerignore` and compose generation for `@deltabox/toolchain`.

- `dockerFiles()` renders the artifacts for a project; `writeDockerFiles()`
  writes them (used by `dbx create --containerize`).
- The files are generated once at scaffold time and are **not** `dbx sync`-managed
  afterwards, so they can be edited freely.
- Vite+ projects build with `ghcr.io/voidzero-dev/vite-plus`; Bun projects use
  `oven/bun`, and other Node projects use `node:<version>`.
- Multi-stage builds, non-root runtime users, an HTTP `HEALTHCHECK` and a local
  compose file are generated by default when scaffolding.

```ts
import { dockerFiles, writeDockerFiles } from '@deltabox/toolchain/docker';

const files = dockerFiles({ cwd: process.cwd(), image: 'acme/api', port: 3000 });
writeDockerFiles({ cwd: process.cwd(), compose: true, force: true });
```
